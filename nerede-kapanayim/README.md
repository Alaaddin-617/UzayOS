# Alan Kilit güncellemesi

Bu klasör eski sürümlerin güncelleme bağlantısının çalışmaya devam etmesi için tutulur. Projenin güncel adı ve dosyaları **Alan Kilit** adıyla `alan-kilit` klasöründedir.

Güncel uygulamayı tarayıcıda açıp cihazına kur: https://alaaddin-617.github.io/UzayOS/

Eski sürümün güncelleme denetimi için son sürüm bilgisi: [version.json](version.json)
